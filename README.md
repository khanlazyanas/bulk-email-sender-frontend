# 🚀 Bulk Email Sender - Enterprise SaaS Frontend

**🌟 Live Demo:** [https://bulk-email-sender-frontend-two.vercel.app]

An ultra-premium, high-performance frontend for a bulk email outreach platform. Built with a focus on cinematic UI/UX, real-time telemetry simulation, and developer-first architecture.

## ✨ Key Features
*   **Cinematic Glassmorphism UI:** Advanced Tailwind CSS techniques with deep space ambient glows and 3D floating elements.
*   **Holographic Rich Text Editor:** Fully functional, custom-built `contentEditable` editor supporting Bold, Italic, Links, and Media without external heavy packages.
*   **Real-Time Dashboard Simulation:** Skeleton loading states and breathing SVG charts for a live data feel.
*   **Smart Contact Management:** Real-time search, status filtering, and dynamic pagination.
*   **100% Mobile Responsive:** Carefully scaled 3D mockups and a smooth slide-in mobile drawer.

## 🛠️ Tech Stack
*   **Framework:** Next.js (App Router)
*   **Styling:** Tailwind CSS (Custom arbitrary variants & animations)
*   **Language:** TypeScript / JavaScript
*   **Icons:** Custom SVG Vectors

## ⚙️ How to Run Locally
If you want to run this project on your local machine, follow these steps:

1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm run dev` to start the development server
4. Open `http://localhost:3000` in your browser
